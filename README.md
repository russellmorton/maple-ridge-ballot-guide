# Maple Ridge Ballot Guide (archived)

Independent, non-partisan guides to two elections a week apart in October 2026. **Both elections are over. The site is an archive of the campaigns and is no longer updated.**

- **Municipal, October 17, 2026** (`/municipal`): every candidate for mayor, council and SD42 school trustee, the three recreation borrowing questions, issue-by-issue comparisons, and the official results declared on October 21.
- **Provincial, October 24, 2026** (`/provincial`): every candidate in Maple Ridge's two ridings and the ridings next door, what each party promised, and the final-count results declared on November 9.

Every position and result links to its source. Not affiliated with the City of Maple Ridge, School District 42, Elections BC, the Government of B.C., any party, candidate or elector organization.

## What the archive removed

On November 19, 2026 the site became fully static:

- **Ask the guide** (the AI assistant), **Find your riding** (the address lookup) and the **feedback form** were removed, along with all server code (`api/`, `lib/`) and its dependencies.
- **Vercel Web Analytics** was removed.
- **Candidates' email addresses and phone numbers** were removed from both data files. Websites stay.

Both guides open in their after-the-vote layout: an archive notice, the results, and no ballot or vote planner. The change logs on each About page list everything that changed.

## Structure

Static site, no build step and no server code.

| File | What it holds |
| --- | --- |
| `index.html`, `landing.js` | Landing page: one card per election. Also forwards old links (`/#candidates`, `/#c-ruimy`) to `/municipal`. |
| `guide.css`, `theme.js` | Shared layout, styles (light and dark) and the theme toggle. Each guide sets its own palette. |
| `municipal/data.js` | **All municipal content**: candidates, positions, sources, ballot questions and official `results` |
| `municipal/app.js` | Municipal rendering: results, candidates, comparison grid |
| `provincial/data.js` | **All provincial content**: ridings with 2024 and 2026 results, candidates, parties and platforms, the province-wide `outcome` |
| `provincial/app.js` | Provincial rendering: results, ridings, candidates, parties, compare |
| `provincial/map.js` | Riding outlines for the map, generated by `scripts/fetch-districts.mjs` from DataBC's *Current Provincial Electoral Districts of British Columbia* |
| `vercel.json` | Clean URLs and security headers |

`npm test` checks that every source, riding, party and stance resolves, that the results match the candidates and the declared winners, and that nothing calls removed services or carries candidates' contact details.

## Run locally

```sh
npm test
npx serve .
```

## Deploy

Live at **https://vote-maple-ridge.vercel.app**. The Vercel project stays in place so nobody else can claim the address. Merging into `main` deploys to production; `main` only accepts changes through pull requests.
